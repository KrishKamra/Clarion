# Clarion

> **Clear Intent. Conscious Commerce.**

Clarion is an intelligent e-commerce Decision Support System (DSS) designed to transform online shopping from mindless impulse scrolling into deliberate, goal-oriented commerce. Rather than promoting algorithmic consumerism, Clarion empowers users to evaluate purchasing trade-offs, align purchases with personal intent, enforce budget boundaries, and eliminate impulse buying.

---

## 🎯 Key Feature Pillars

| Pillar | Description |
| :--- | :--- |
| 🔍 **Intent-First Search** | Query by purpose (e.g., *"Set up an ergonomic workstation for deep focus work"*) rather than keyword scrolling. |
| 📊 **Personal Fit Score Heuristics** | Contextual match percentages calculating how effectively a product satisfies specific user intent and constraints. |
| 🛡️ **Budget Guardian** | Proactive budget defense tracking real-time financial headroom and evaluating long-term purchase impact. |
| ⏳ **Anti-Impulse Guards** | Cooling-off timers, trade-off friction, and mindfulness prompts that eliminate accidental or emotional spending. |

## 🚀 Getting Started

### Prerequisites
- [Flutter SDK](https://docs.flutter.dev/get-started/install) installed locally.
- Android Studio, VS Code, or IntelliJ IDEA with Flutter & Dart plugins.

### Local Setup Instructions

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/clarion.git
   cd clarion
   ```

2. **Fetch dependencies:**
   ```bash
   flutter pub get
   ```

3. **Run the application:**
   ```bash
   flutter run
   ```
